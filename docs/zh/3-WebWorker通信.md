# 3-WebWorker 通信

## 背景

为保证主线程渲染流畅，SVG 表格组件将数据的排序、过滤、分组等重计算任务交由 Web Worker 处理。主线程与 Worker 之间需要高效、可靠的数据通信协议。

## 实现细节

- 主线程与 Worker 通过 `postMessage` 进行异步通信。
- 采用结构化克隆算法传递数据，避免深拷贝性能损耗。
- 支持增量数据同步，减少全量数据传输。
- 设计统一的消息格式，区分请求类型（排序、过滤、分组等）。
- Worker 支持任务中断、错误上报。

## 待解决问题

- **Worker 任务的中断、错误处理机制。**
- **大数据量下的增量同步与性能瓶颈。**
- **多 Worker 协作或 Worker 池的可扩展性。**
- **通信协议的版本兼容与扩展能力。**
