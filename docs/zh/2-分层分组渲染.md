# 2-分层分组渲染

## 背景

在 SVG 虚拟滚动表格中，分层与分组渲染是实现高性能和灵活交互的关键。通过将表头、表体、选中高亮、编辑控件等内容分层管理，并对同类单元格进行分组，可以提升渲染效率、便于样式和事件管理。

## 实现细节

- 使用 `<g>` 标签将表头、表体、选中、编辑等不同内容分层管理。
- 同一行/列/区域的单元格用 `<g>` 包裹，便于批量设置样式和事件。
- 分层结构便于单独刷新局部内容，减少无关重绘。
- 分组有助于事件委托和热点区域优化。
