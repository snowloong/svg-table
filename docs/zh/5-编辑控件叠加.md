# 背景

SVG 表格组件支持单元格和行的编辑能力，需在 SVG 上方叠加原生 DOM 编辑控件（如 <input>、<select>），实现无缝交互体验。控件的定位、样式和数据同步是实现难点。

---

## 实现细节
- 用户点击单元格时，计算其在页面上的绝对位置。
- 在 SVG 上方插入 HTML 编辑控件，并用 CSS 绝对定位到对应位置。
- 编辑完成后，将新值同步到数据源，销毁控件并重新渲染 SVG。
- 支持键盘导航、批量编辑、校验等高级功能。

---

## 待解决问题

- 编辑状态下的键盘事件冲突与焦点管理。
- 多类型控件（input/select/textarea）适配与统一。
- 编辑控件与虚拟滚动、节点池的协同。
