# 4-列宽行高动画

## 背景

SVG 表格组件支持用户拖拽调整列宽和行高，并通过 FLIP 动画实现平滑过渡，提升交互体验。动态调整和动画实现需兼顾性能与流畅性。

## 实现细节

- 拖拽调整时，实时计算并更新对应单元格的宽度/高度。
- 采用 FLIP（First-Last-Invert-Play）动画原理，实现列宽/行高变化的平滑过渡。
- 动画过程在 `requestAnimationFrame` 中执行，保证主线程流畅。
- 支持批量调整和撤销操作。
