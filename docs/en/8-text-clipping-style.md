# 8-文本裁剪与样式

## 背景

SVG 表格组件需支持单元格内容的文本溢出、裁剪和样式统一，保证内容展示美观且不影响布局。

## 实现细节

- 超长文本用 `<text>` + `text-overflow` 或 `<clipPath>` 裁剪。
- 统一管理字体、颜色、对齐等样式，避免样式错乱。
- 支持多行文本、自动换行、对齐方式自定义。
- 文本样式与主题切换、暗黑模式兼容。

## 待解决问题

- **不同浏览器下 SVG 文本裁剪与样式兼容性。**
- **多语言、特殊字符下的文本溢出处理。**
- **文本与单元格尺寸、缩放的自适应。**
- **样式统一与自定义样式的冲突。**
